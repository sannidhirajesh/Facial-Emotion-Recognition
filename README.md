# Facial Emotion Recognition

A computer vision project that detects a person's facial emotion from an uploaded image using a pre-trained deep learning model.

## Features

- Upload JPG, JPEG,jfif or PNG images
- Automatic face detection
- Emotion prediction from facial expressions
- Confidence score display
- Simple and user-friendly Streamlit interface

## Technologies Used

- Python
- Streamlit
- OpenCV
- PyTorch
- Transformers
- NumPy
- Pillow

## How It Works

1. Upload an image.
2. The application detects the face in the image.
3. The detected face is processed using a pre-trained facial emotion recognition model.
4. The model predicts the dominant emotion.
5. The emotion and confidence score are displayed.
